# Web inspect — أدوات فحص صفحة حيّة بالعين وبالقياس

أدوات صغيرة بلا تبعيّات (Python + Chrome فقط) لفحص أي صفحة قبل الحكم عليها.
بُنيت أثناء فحص `tkawen.com` و`id.tkawen.com` يوم 2026-07-30.

## 🔴 الفخّ الذي استدعى بناءها
`chrome --headless --window-size=390,844 --screenshot` **يكذب على ويندوز**:
النافذة لا تنزل تحت **504 بكسل** (الحدّ الأدنى للنظام)، فتُرسم الصفحة بعرض 504
ثمّ **تُقصّ اللقطة** إلى 390. في صفحة RTL يُقتطع الجانب الأيمن، فتبدو الصفحة
مكسورة تمامًا وهي سليمة. كِدتُ أُبلّغ عن عطب لا وجود له.

**الحلّ**: حمّل الصفحة داخل `iframe` بعرض الجهاز بالضبط — عندها تُحسب
`vw`/`vmax` واستعلامات الوسائط كما على الهاتف تمامًا.

## الأدوات
| الملفّ | ماذا يفعل |
|---|---|
| `shot_phone.py <url> <w> <h> <out.png>` | لقطة بعرض هاتف **حقيقيّ** (تقنيّة الإطار) |
| `measure2.py <url> [w] [h]` | يقيس `scrollWidth` والتجاوز الأفقيّ ويسمّي كلّ عنصر يتجاوز الإطار |
| `measure.py` | النسخة الأولى (تقيس على النافذة مباشرة) — احتفظ بها للمقارنة فقط |
| `contrast.py <url>` | نسبة تباين WCAG لكلّ نصّ مقابل خلفيّته الفعليّة، بما فيها `::placeholder` |
| `find_h1.py` · `header_login.py` | أمثلة استخراج قواعد CSS وروابط من HTML على الخادم |

## أدوات الطاقة (من نفس اليوم)
| الملفّ | ماذا يفعل |
|---|---|
| `wol.ps1` | يرسل حزمة إيقاظ إلى المحمول من **نفس الشبكة**؛ يعمل من النوم لا من الإطفاء الكامل |
| `fix_power_admin.ps1` | يكشف إعداد إغلاق الغطاء المخفيّ ويضبطه، ويخفض توفير طاقة الواي-فاي (يحتاج مسؤولًا) |

🔴 **ملفّات `.ps1` بمحارف ASCII فقط**: Windows PowerShell 5.1 يقرأها بترميز ANSI
ما لم تحمل BOM، فشرطة طويلة واحدة تكسر التحليل كلّه.
